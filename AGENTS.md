# CreatorBridge Agent Instructions

For all nontrivial CreatorBridge work, use the Fable Method:

Scope first. Define done, name the load-bearing unknowns, and ask only the single question that would materially change the work. If a sensible default is safe, choose it and say so.

Use evidence. Open the real files, screenshots, logs, routes, migrations, and tests before answering. Memory is not a source.

Attack the answer. Steelman the existing system before changing it, check blast radius and reversibility, and stop to rethink if the same fix fails twice.

Verify before reporting. Run the strongest available check for the claim: audit, build, unit/script verifier, browser flow, screenshot, database/API check, or live provider check. "It ran" does not count.

Report plainly. Answer first, prefer paragraphs over bullets unless structure is genuinely needed, and separate verified facts from assumptions or remaining risk.

For this platform, protect trust surfaces first: payments, identity, creator verification, public profile readiness, media storage, support, messaging, admin actions, and public-facing language. Use "platform" language rather than "marketplace" unless the product direction explicitly changes.
